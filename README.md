# Abstraction
- Blue-Ga is a simple music streaming application which allows the user to upload their own songs and conversely listen to songs uploaded by another user.
- The songs themselves follows a set structure, i.e., each and every song must be contained within an album. An album may have 3 types: Single (A single song  or up to 3), EP (Shorter 15 to 25 min listens), LP (Long 45 min+ listens).
## Architecture
- The frontend will be built on **React** and **Bootstrap** for easy styling.
- The database used is **MongoDB**.
- **Spring Boot** is used to create controllers and endpoints that handle http requests.
- **Maven** is the dependency management tool for the Spring Boot framework.
